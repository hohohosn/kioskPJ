# 키오스크 프로젝트

간단한 콘솔 기반의 햄버거 키오스크 프로그램입니다.  
객체지향 설계를 기반으로 메뉴 선택, 장바구니 추가, 주문/취소 기능을 구현했습니다.

---

## 사용 기술

Java 17

IntelliJ IDEA

---

## 주요 기능

-  메인 메뉴 → 서브 메뉴 탐색
-  메뉴 선택 시 장바구니에 추가 여부 확인
-  장바구니 내역 출력 및 총액 계산
-  유효하지 않은 입력에 대한 예외 처리

---

## Class 구조 및 설명

| Class         | 역할 |
|---------------|----------------|
| `Main`        | 프로그램 실행 진입점. 메뉴 구성 후 Kiosk 실행 |
| `Kiosk`       | 전체 프로그램 흐름 제어, 사용자 입력 처리 |
| `Menu`        | 메뉴 이름과 `MenuItem` 리스트 관리 |
| `MenuItem`    | 메뉴 항목 이름, 가격, 설명 관리 |
| `Cart`        | 장바구니 항목 관리, 출력 및 총합 계산 |
| `CartItem`    | 장바구니에 담긴 개별 항목 (상품 + 수량) |
